# Hospital Management System - Full Stack

This is the Full Stack application for the Hospital Management System, built with React. It provides distinct user interfaces for patients, doctors, and administrators to interact with the platform.

## 🔗 Live Demo
- **Frontend App**: [https://hospital-system-three-hazel.vercel.app](https://hospital-system-three-hazel.vercel.app)
- **Backend API**: [https://med-flow.onrender.com](https://med-flow.onrender.com)

## 🚀 Key Features

- **Admin Dashboard**: Comprehensive view for hospital administrators to manage departments, doctors, and overall system settings.
- **Doctor Dashboard**: Interfaces for doctors to view their upcoming appointments, manage their schedules, and interact with patient cases.
- **Patient Interface**: Secure authentication pages for patients to log in, browse available doctors by department, and seamlessly book appointments.
- **Responsive Design**: Custom styled with vanilla CSS for a modern, fast, and responsive user experience across different devices.

## 🛠️ Technology Stack

- **React 19**: Core library for building user interfaces.
- **React Router DOM v7**: Handles client-side routing and navigation between pages.
- **Testing Library & Jest**: Frameworks for robust unit and component testing.

## 🏃‍♂️ Running Locally

In the project directory, you can run the following scripts:

### `npm install`
Installs all the required dependencies to run the frontend application.

### `npm start`
Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will automatically reload when you make changes.

### `npm test`
Launches the test runner in interactive watch mode for running unit tests.

### `npm run build`
Builds the app for production to the `build` folder. It correctly bundles React in production mode and optimizes the build for the best performance. The build is minified, and the filenames include hashes. Your app is ready to be deployed!
